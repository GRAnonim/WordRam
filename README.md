# Wordra

Wordra — игра в филворд.

## Язык
- Интерфейс и настройки: русский.
- Игровые слова: английский.

## Правила
1. Только соседняя клетка.
2. Только горизонталь или вертикаль.
3. Диагональные переходы запрещены.
4. Перепрыгивание через клетки запрещено.
5. Повторное использование одной клетки в одном слове запрещено.
6. Слово можно провести в обратную сторону.
7. Основные слова обязаны физически существовать на поле.
8. Генератор валидирует каждый уровень перед показом игроку.
9. Bonus words необязательны и не заменяют основные слова.
10. Bonus words могут быть короче или длиннее основных и могут пересекаться.

# Wordra

Мобильная игра-головоломка: интерфейс и настройки на русском, игровые слова — английские.

## Правила Wordra

- Слово собирается только по горизонтали или вертикали.
- Переход только между соседними клетками.
- Диагональные переходы запрещены.
- Перепрыгивание через клетки запрещено.
- Клетку нельзя использовать дважды в одном слове.
- Слово можно проводить в обратном направлении.
- Основные слова обязаны физически существовать на поле.
- Генератор не принимает уровень, пока все основные слова не проходят валидатором.
- Bonus words необязательны и дают дополнительные монеты.
- Bonus words могут отличаться по длине и пересекаться с основными словами.

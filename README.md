# WordRam

Мобильный филворд с русским интерфейсом и английскими словами.

Правила:
- только соседние клетки;
- только горизонталь/вертикаль;
- без диагоналей;
- без прыжков;
- без повторного использования клетки в одном слове;
- направление может меняться на каждом шаге;
- основные слова не показываются игроку заранее;
- основные слова генерируются по ломаным маршрутам минимум с двумя поворотами;
- bonus words необязательны;
- подсказка открывает маршрут по одной букве за нажатие.
